    펼쳐보기 · 집계 기준 안내
    • 유입(세션) = 이벤트 페이지로 처음 들어온 세션이에요 (GA4 랜딩 페이지가 이벤트 경로로 시작). 사이트 안에서 이동해 온 경우는 '사이트 내 유입 경로'의 페이지뷰로 봐요.
    • 기간 비교 = 선택한 기간과 같은 길이의 바로 앞 기간이에요. 앞 기간이 모집 시작 전이면 비교하지 않아요.
    • UTM 캠페인 비중 = utm 파라미터가 붙은 링크로 들어온 세션 ÷ 전체 세션이에요. 검색·직접 유입은 빠져요.
    • 참여율 = 10초 이상 머물렀거나, 페이지를 2개 이상 봤거나, 전환이 있었던 세션의 비율(GA4 정의)이에요. 평균 참여 = 참여 시간 합계 ÷ 세션이에요.
    • 신청 건수(창업지원센터) = 왈라 신청서로 접수된 응답 수예요. 유입 출처는 신청자가 신청서에서 직접 고른 답이에요.
    • 직접 유입 = 리퍼러도 UTM도 없는 방문이에요. 메신저 앱 내 브라우저·북마크·주소 직접 입력이 여기로 들어가요. 창업지원센터 EMS 이메일은 왈라 신청서로 바로 연결돼 페이지 유입에는 잡히지 않아요.
